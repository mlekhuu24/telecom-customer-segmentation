# Telecom Customer Segmentation using Python + Scikit-learn

## Project Overview
This machine learning project groups telecom customers into segments based on their usage, charges, tenure, and support activity.

## Algorithm
- K-Means Clustering
- StandardScaler
- Silhouette Score for evaluation

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Joblib

## Input Features
- Tenure in months
- Monthly charge
- Total charge
- Data usage in GB
- Call minutes
- Support calls

## How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the segmentation model
```bash
python train_model.py
```

This creates:
- `telecom_segmentation_model.pkl`
- `customer_segments.png`
- `segmented_customers.csv`

### 3. Assign a new customer to a segment
```bash
python predict.py
```

## Understanding Segments
The segment numbers are generated by K-Means. They do not have fixed meanings automatically. Analyze the average values of each segment to label them, such as:
- High-value customers
- Low-usage customers
- Heavy data users
- Customers needing support

## Important Note
The included dataset is synthetic and intended for educational demonstration. Use real, validated customer data for production decisions and protect customer privacy.
